    How it works

    1. Structure: drop an XYZ, PDB, SDF or MOL2 file.
    2. Task: conformer search, optimisation, IR spectrum, microsolvation…
    3. Model: pick the potential; the GUI runs it in an environment that has it.
    4. Run: follow the log and see structures, ensembles and spectra in Jobs.

    Every job is an ordinary mars command line, shown before it runs and saved with the job, so any GUI run can be repeated from a terminal or a cluster script.
