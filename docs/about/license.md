## Bundled reference data

Solvent geometries under `mars/solvents/library/` and the periodic-table
arrays in `mars/utils.py` are derived from publicly available scientific
data (NIST CCCBDB, IUPAC, Pyykkö 2009, Bondi 1964, Mantina 2009). See
the [Citation](citation.md) page for the full list of references.
